# syncBoard

Full-stack assignment project.

## Structure

- `client/` — React app (Vite), frontend
- `server/` — backend (coming soon)

## Getting started

```bash
cd client
npm install
npm run dev
```

## Branching

Repo: https://github.com/AreebHanas/full_stack_assignment.git

Everyone works on their own branch — do not commit directly to `main`. Name your branch after the feature/fix you're implementing, in the format `type/short-name`:

- `feature/login` — new feature
- `bugfix/navbar-overlap` — bug fix
- `feat/dashboard-charts` — new feature (short form)
- `fix/api-timeout` — quick fix
- `chore/update-deps` — maintenance, no feature/fix

```bash
git checkout -b feature/login
```

Open a pull request into `main` when your branch is ready for review.
